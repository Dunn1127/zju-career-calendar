# 浙大宣讲日历

**[打开浙大宣讲日历](https://dunn1127.github.io/zju-career-calendar/)** · **[GitHub源码](https://github.com/Dunn1127/zju-career-calendar)**

独立于大工项目的浙江大学校园招聘日历。个人开源项目，非学校官方产品；活动安排以[浙江大学就业服务平台](https://www.career.zju.edu.cn/)为准。

## 使用方式

网页与 iPhone 主屏幕 PWA，安卓也可通过浏览器访问。用 Safari 打开公开网址，分享→添加到主屏幕；如有“作为网页 App 打开”，请开启。首版不提供安卓 APK。

支持过去5天至未来15天内的宣讲会（含空中宣讲）和双选会、搜索、校区/楼宇筛选、时间轴和周历、收藏、时间冲突提示及ICS导出。校区无法确定时显示“校区待确认”。搜索也覆盖公开招聘正文，不把正文编造成结构化岗位列表。

仅官网明确提供完整起止时间且未取消的活动可导出ICS；不把隐藏的场地预约时段当成宣讲时长。取消活动会明确标注并排除冲突和导出。导入日历后不自动同步变更，提醒效果取决于接收日历应用。

收藏保存在当前浏览器或桌面版，不跨设备同步。首次联网缓存完成后可离线查看旧日程；缓存可能被系统清理。大工与浙大使用不同的收藏键、缓存名、ICS UID和Service Worker路径，不互相覆盖。

## 数据与更新

读取官网公开月度接口 `/v5-api/jyxt/wzsy/cxZprlList.zf?rq=YYYY-MM`，遍历窗口涵盖的所有月份，合并ID再筛选日期。类型xjh、kzxjh、zph对应宣讲、空中宣讲与双选会，通用招聘公告不列入活动日历。详情读取对应的公开HTML页面，并清理脚本、联系人、电话和邮箱。

北京时间每天下午16:00计划在GitHub Actions采集一次，实际调度可能延迟；手动和main代码发布也可触发。请求与任务均支持失败重试，不设置额外定时补跑。列表不完整或失败不覆盖旧快照；个别详情失败保留旧详情/摘要，原站暂时消失只标记“暂未查到”。

每次打开先检查约百余字节的版本文件，版本未变复用本地快照；页面内10分钟节流；新版本下载后核对SHA256。联网恢复会重新检查，超过26小时未成功采集提示过期。静态资源版本更新会在旧应用窗口全部关闭后启用。

访问统计沿用Cloudflare Web Analytics站点标识，在后台按 `/zju-career-calendar/` 区分。仅页面与性能统计，不上传搜索词或收藏事件。

## 开发与验证

Node.js 24：`npm ci` → `npm test` → `npm run collect` → `npm run build`。

`npm run preview` 在本机4174端口提供dist；`npm run dev`提供site。离线测试需使用dist。

启动预览后运行 `npm run test:browser`、`node browser-tests/pwa-check.mjs`。可用CALENDAR_TEST_URL指定线上网址。截图和报告保存在上级工作区 `.omo/evidence/zju/`。真实活动对照样例、云端运行及两站隔离结果在交付记录中提供。

苹果真机安装、离线行为及系统日历导入需要真机确认，浏览器或模拟器结果不代表真机已验证。
